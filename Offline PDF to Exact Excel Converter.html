● 100% Air-Gapped Offline Architecture

This single HTML file contains zero external runtime dependencies for PDF parsing or Excel generation:

  • Pure-JS PDF Stream & Operator Engine: Parses PDF cross-reference tables/objects, decompresses /FlateDecode streams natively via the browser's built-in DecompressionStream('deflate') API, decodes ToUnicode CMap font tables, and extracts exact Tm / Td / TJ text matrices alongside m / l / re vector gridlines.
  • Hybrid Grid & Merged-Cell Reconstructor: Snaps vector border segments into canonical X/Y grid tracks, groups multi-line entries inside cells, and infers horizontal (colspan) and vertical (rowspan) merged cells where dividing lines are omitted.
  • Native OpenXML (.xlsx) & ZIP Builder: Generates standards-compliant xl/worksheets/sheet*.xml with <mergeCells>, cell borders, word-wrap styles, and CRC32-checksummed ZIP archives directly in memory.
How to use completely offline: Press Ctrl+S (or Cmd+S) to save this page as pdf_to_exact_excel.html on your computer, then open it anytime in Chrome, Edge, Firefox, or Safari without Wi-Fi.
